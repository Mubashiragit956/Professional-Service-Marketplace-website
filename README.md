> This is my 4-week internship project. The project name is Professional Service Marketplace Website.
>
> This website is a platform where users can find different professional services. It includes several pages like Home, Services, Providers, About, Blog, and Contact Us.
>
> On the Home page, there are 3 main services. Each service is explained in detail with Problem, Solution, and Benefit. There is also an accordion feature to show and hide the details.
>
> On the Providers page, we can see the profiles of different service providers.
>
> The website also has a Blog section for latest articles and an Enquiry Form with validation to contact us.
>
> This website is fully responsive on all devices (mobile, tablet, and desktop) and is developed using HTML, CSS, and JavaScript. I have used separate files for HTML, CSS, and JS.
>
